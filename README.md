# ShopSphere

A role-based MERN marketplace for customers and independent sellers.

## Project layout

- `backend`: Express, MongoDB, JWT authentication, product uploads, inventory-safe checkout, and seller order management.
- `frontend`: Vite React storefront with search, sorting, cart, checkout, profiles, order cancellation, and seller tools.

## Run locally

1. Install dependencies in both `backend` and `frontend`.
2. Copy each `.env.example` to `.env` and adjust the URLs if needed.
3. Start MongoDB.
4. Run `npm run dev` in both folders.

See the folder README files for production environment variables and hosting notes.
